How to Clone

If you don't like any of the forks, then make your own
  1. Create a github account or an account of whatever platform the repo is using for the second step.
  2. Fork all the official repos or repos of your choice which you can find here, make sure they all have the same structure.
  3. clone the repo to your computer so you can edit it using github desktop if you want to edit it long-term or if you jsut want to make a few quick changes, open it in vscode.dev with "Open Remote Repository"
  4. Edit it to your liking +whatever the repo specifies, for this repo, you HAVE to edit the _config.yml to what fits for you. make sure to make the repo your own(except when it comes to structure, please keep it the same unless you absolutely want to change it) although you HAVE to keep the credits & also provide credits to the repo you took from
  5. follow the hosting instructions for that repo, for this repo
    1. go to your forks settings & enable pages with github actions
  6. contact me at ublcdkgms@gmail.com to add your forks to the tracker
